# App de Mantenimiento Técnico

Versión web offline/estática construida a partir de la información e imágenes proporcionadas para el manual.

## Uso
Abrir `index.html` en un navegador. Para instalarla en un servidor o empaquetarla como aplicación móvil, puede utilizarse Capacitor, Cordova o una WebView.

## Incluye
- Búsqueda de equipos.
- Rutinas paso a paso.
- Parámetros y referencias técnicas.
- Seguridad y EPP.
- Galería técnica con imágenes del documento proporcionado.
- Módulos de electromecánicos, hornos, fermentación, refrigeración y congelado.
